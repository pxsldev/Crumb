Crumb is completely free to use, with no paid features or subscriptions.

## 📌 About This Repository

This repository contains the source code for Crumb.

The code is open source so the community can:

* 🐛 Report bugs
* 💡 Suggest improvements
* 🔧 Contribute fixes and features
* 📖 Learn from the project

This repository is intended to help improve the official Crumb project rather than create separate competing hosted versions.

## ⚠️ Self Hosting

Self-hosting Crumb is **not officially supported**.

The code may depend on:

* private configuration
* external services
* internal systems
* infrastructure that is not included in this repository

You are welcome to look through the code and contribute, but getting your own instance running is not guaranteed.

## 🛠️ What Is Crumb?

Crumb is focused entirely on server management and utility features.

It is built to help Discord server owners and moderators manage their communities with a collection of useful tools and automated systems.

Features include things such as:

* 🛡️ Server security
* 🚨 Anti-raid protection
* 💥 Anti-nuke protection
* 🔨 Moderation
* 🎫 Server utilities
* ✅ Verification
* 📈 Levelling
* 🎭 Reaction roles
* And more

The goal is simple:

**Crumb is built to help you run your server.**
